\\section{Construyendo Frases - Operadores y Expresiones}\n\\label{sec:operadores_expresiones}\n\nHasta ahora, hemos aprendido c\\'omo almacenar datos en variables. Pero almacenar informaci\\'on no es suficiente; necesitamos poder \\textbf{manipular} esos datos, combinarlos y realizar operaciones con ellos. Para esto, C++ nos proporciona un conjunto de herramientas llamadas \\textbf{operadores}.\n\nUn \\textbf{operador} es un s\\'imbolo que le dice al compilador que realice una operaci\\'on espec\\'ifica en uno o m\\'as operandos (variables o valores). Una \\textbf{expresi\\'on} es una combinaci\\'on de variables, constantes y operadores que el programa eval\\'ua para producir un valor.\n\n\\subsection{Operadores Aritm\\'eticos: Las Operaciones Matem\\'aticas B\\'asicas}\n\\label{subsec:operadores_aritmeticos}\n\nLos operadores aritm\\'eticos son los que usamos para realizar c\\'alculos matem\\'aticos b\\'asicos. En C++, estos son:\n\n\\begin{itemize}\n    \\item \\textbf{\\texttt{+}:} Suma dos valores.\n    \\item \\textbf{\\texttt{-}:} Resta el segundo valor del primero.\n    \\item \\textbf{\\texttt{*}:} Multiplica dos valores.\n    \\item \\textbf{\\texttt{/}:} Divide el primer valor por el segundo.\n    \\item \\textbf{\\texttt{\\%}:} Devuelve el resto de la divisi\\'on entera.\n\\end{itemize}\n\nVeamos algunos ejemplos pr\\'acticos:\n\n\\begin{lstlisting}[language=C++]\n#include <iostream>\nusing namespace std;\n\nint main() {\n    int a = 10;\n    int b = 3;\n    \n    cout << \"a = \" << a << \", b = \" << b << endl;\n    cout << \"Suma (a + b): \" << a + b << endl;      // Resultado: 13\n    cout << \"Resta (a - b): \" << a - b << endl;     // Resultado: 7\n    cout << \"Multiplicacion (a * b): \" << a * b << endl; // Resultado: 30\n    cout << \"Division (a / b): \" << a / b << endl;  // Resultado: 3 (division entera!)\n    cout << \"Modulo (a % b): \" << a % b << endl;    // Resultado: 1 (resto de 10/3)\n    \n    return 0;\n}\n\\end{lstlisting}\n\n\\subsubsection{La Trampa de la Divisi\\'on Entera}\n\\label{subsubsec:division_entera}\n\nObserva atentamente el resultado de la división en el ejemplo anterior. Aunque 10 dividido entre 3 es 3.333..., obtenemos 3 como resultado. \\cquestion{¿Por qu\\'e?} Porque ambos operandos son n\\'umeros enteros (\\texttt{int}), por lo que C++ realiza una \\textbf{divisi\\'on entera}, descartando cualquier parte decimal.\n\nEsta es una de las trampas m\\'as comunes para los principiantes en C++. Para obtener una división que preserve los decimales, al menos uno de los operandos debe ser de tipo \\texttt{double}:\n\n\\begin{lstlisting}[language=C++]\n#include <iostream>\nusing namespace std;\n\nint main() {\n    int a = 10;\n    int b = 3;\n    \n    // Division con enteros (resultado entero)\n    cout << \"Division entera: \" << a / b << endl;  // Resultado: 3\n    \n    // Division con decimales (resultado con decimales)\n    cout << \"Division decimal: \" << (double)a / b << endl;  // Resultado: 3.33333\n    cout << \"Division decimal: \" << a / (double)b << endl;  // Resultado: 3.33333\n    cout << \"Division decimal: \" << 10.0 / 3 << endl;       // Resultado: 3.33333\n    \n    return 0;\n}\n\\end{lstlisting}\n\nEn el ejemplo anterior, usamos \\texttt{(double)a} y \\texttt{(double)b} para \\textbf{convertir} temporalmente las variables a tipo \\texttt{double}. Esta operación se llama \\textbf{casting} y es una forma de cambiar el tipo de una variable temporalmente.\n\n\\subsection{Precedencia de Operadores: El Orden Importa}\n\\label{subsec:precedencia_operadores}\n\nAl igual que en matem\\'aticas, en C++ los operadores tienen un orden de precedencia que determina qu\\'e operaciones se realizan primero. El operador de multiplicaci\\'on, divisi\\'on y m\\'odulo tienen mayor precedencia que la suma y la resta.\n\nConsidera esta expresión: \\texttt{5 + 3 * 2}. \\cquestion{¿El resultado es 16 o 11?} La respuesta correcta es 11, porque la multiplicación se ejecuta antes que la suma. Primero se calcula \\texttt{3 * 2 = 6}, luego \\texttt{5 + 6 = 11}.\n\n\\begin{lstlisting}[language=C++]\n#include <iostream>\nusing namespace std;\n\nint main() {\n    int resultado1 = 5 + 3 * 2;    // 11, no 16\n    int resultado2 = (5 + 3) * 2;  // 16\n    \n    cout << \"5 + 3 * 2 = \" << resultado1 << endl;\n    cout << \"(5 + 3) * 2 = \" << resultado2 << endl;\n    \n    return 0;\n}\n\\end{lstlisting}\n\nUsar par\\'entesis no solo cambia el orden de operaciones, sino que tambi\\'en mejora la \\textbf{legibilidad} del c\\'odigo. Aunque no cambie el resultado, es una buena pr\\'actica usar par\\'entesis para aclarar la intenci\\'on de tu c\\'odigo:\n\n\\begin{lstlisting}[language=C++]\nint area_triangulo = (base * altura) / 2;  // Más claro que: base * altura / 2\n\\end{lstlisting}\n\n\\subsection{Operadores de Asignaci\\'on Compuesta: Atajos del Lenguaje}\n\\label{subsec:operadores_asignacion_compuesta}\n\nImagina que tienes una variable que representa el saldo de una cuenta bancaria y necesitas sumarle un dep\\'osito. Podr\\'ias escribir:\n\n\\begin{lstlisting}[language=C++]\nsaldo = saldo + deposito;\n\\end{lstlisting}\n\nC++ ofrece una forma m\\'as concisa de escribir esta operación com\\'un usando operadores de asignación compuesta:\n\n\\begin{itemize}\n    \\item \\textbf{\\texttt{+=}:} \\texttt{saldo += deposito;} equivale a \\texttt{saldo = saldo + deposito;}\n    \\item \\textbf{\\texttt{-=}:} \\texttt{saldo -= retiro;} equivale a \\texttt{saldo = saldo - retiro;}\n    \\item \\textbf{\\texttt{*=}:} \\texttt{precio *= 1.19;} equivale a \\texttt{precio = precio * 1.19;} (agregar IVA)\n    \\item \\textbf{\\texttt{/=}:} \\texttt{promedio /= total;} equivale a \\texttt{promedio = promedio / total;}\n    \\item \\textbf{\\texttt{\\%=:}} \\texttt{resto \\%= divisor;} equivale a \\texttt{resto = resto \\% divisor;}\n\\end{itemize}\n\nEstos operadores no solo hacen el código más conciso, sino que también pueden ser más eficientes en ciertos contextos, especialmente cuando se trabaja con tipos de datos complejos que aprender\\'as m\\'as adelante.\n\n\\begin{lstlisting}[language=C++]\n#include <iostream>\nusing namespace std;\n\nint main() {\n    int puntuacion = 100;\n    \n    cout << \"Puntuacion inicial: \" << puntuacion << endl;\n    \n    puntuacion += 25;  // Sumar 25 puntos\n    cout << \"Despues de sumar 25: \" << puntuacion << endl;\n    \n    puntuacion -= 10;  // Restar 10 puntos\n    cout << \"Despues de restar 10: \" << puntuacion << endl;\n    \n    puntuacion *= 2;   // Duplicar la puntuacion\n    cout << \"Despues de duplicar: \" << puntuacion << endl;\n    \n    return 0;\n}\n\\end{lstlisting}\n\n\\subsection{Incremento y Decremento: Operaciones Comunes Simplificadas}\n\\label{subsec:incremento_decremento}\n\nIncrementar o decrementar una variable en 1 es una operación tan común que C++ tiene operadores专门 para esto:\n\n\\begin{itemize}\n    \\item \\textbf{\\texttt{++}:} Incremento (suma 1)\n    \\item \\textbf{\\texttt{--}:} Decremento (resta 1)\n\\end{itemize}\n\nEstos operadores pueden usarse de dos maneras:\n\n\\subsubsection{Notaci\\'on Prefija (\\texttt{++variable}) y Postfija (\\texttt{variable++})}\n\\begin{itemize}\n    \\item \\textbf{Prefija (\\texttt{++variable}):} Primero incrementa el valor, luego devuelve el nuevo valor.\n    \\item \\textbf{Postfija (\\texttt{variable++}):} Primero devuelve el valor actual, luego incrementa.\n\\end{itemize}\n\n\\begin{lstlisting}[language=C++]\n#include <iostream>\nusing namespace std;\n\nint main() {\n    int a = 5;\n    int b = 5;\n    int resultado1, resultado2;\n    \n    // Prefijo: primero incrementa, luego asigna\n    resultado1 = ++a;  // a se convierte en 6, luego 6 se asigna a resultado1\n    cout << \"Resultado1 (prefijo): \" << resultado1 << \", a: \" << a << endl; // 6, 6\n    \n    // Postfijo: primero asigna, luego incrementa\n    resultado2 = b++;  // b (que es 5) se asigna a resultado2, luego b se convierte en 6\n    cout << \"Resultado2 (postfijo): \" << resultado2 << \", b: \" << b << endl; // 5, 6\n    \n    return 0;\n}\n\\end{lstlisting}\n\nPara operaciones simples de incremento/decremento sin asignación, ambas formas funcionan igual:\n\n\\begin{lstlisting}[language=C++]\nint contador = 0;\ncontador++;    // Incrementa contador en 1\n++contador;    // También incrementa contador en 1\n\\end{lstlisting}\n\nEn estos casos, la elección depende de la preferencia personal y del equipo de desarrollo, aunque muchos programadores prefieren la forma prefija por razones de eficiencia en tipos de datos complejos que ver\\'as m\\'as adelante.\n\n\\textbf{Recuerda:} Los operadores no solo realizan operaciones matemáticas, sino que también forman parte del lenguaje que usas para expresar tu lógica al ordenador. Dominarlos te permite expresar tus ideas de manera más clara y eficiente.
