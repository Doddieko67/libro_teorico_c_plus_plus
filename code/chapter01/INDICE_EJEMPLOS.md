# Índice de Ejemplos - Capítulo 1

## 1. Hola, Mundo
- **Archivo fuente**: `src/hola_mundo.cpp`
- **Ejecutable**: `bin/hola_mundo`
- **Conceptos**: Programa básico, incluir bibliotecas, función main, salida estándar

## 2. Variables y Tipos de Datos
- **Archivo fuente**: `src/variables.cpp`
- **Ejecutable**: `bin/variables`
- **Conceptos**: 
  - Declaración de variables
  - Inicialización por copia, directa y uniforme
  - Tipos fundamentales: `int`, `double`, `char`, `bool`
  - Constantes con `const`

## 3. Operadores Aritméticos
- **Archivo fuente**: `src/operadores.cpp`
- **Ejecutable**: `bin/operadores`
- **Conceptos**:
  - Operadores básicos: `+`, `-`, `*`, `/`, `%`
  - División entera vs. división con decimales
  - Conversión implícita de tipos

## 4. Precedencia de Operadores y Asignación Compuesta
- **Archivo fuente**: `src/precedencia.cpp`
- **Ejecutable**: `bin/precedencia`
- **Conceptos**:
  - Orden de evaluación de expresiones
  - Uso de paréntesis para controlar precedencia
  - Operadores de asignación compuesta: `+=`, `-=`, `*=`, `/=`, `%=`

## 5. Estructuras de Control
- **Archivo fuente**: `src/estructuras_control.cpp`
- **Ejecutable**: `bin/estructuras_control`
- **Conceptos**:
  - Condicionales: `if`, `else`
  - Bucles: `for` tradicional
  - Bucles basados en rango con `std::vector`

## 6. Funciones
- **Archivo fuente**: `src/funciones.cpp`
- **Ejecutable**: `bin/funciones`
- **Conceptos**:
  - Definición de funciones con tipo de retorno
  - Parámetros y argumentos
  - Paso de parámetros por valor
  - Retorno de valores
